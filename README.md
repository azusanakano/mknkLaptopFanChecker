# ネコシステム社 CPUファンチェッカー v1.3.1

ノート型・デスクトップ型パソコンの再生・整備工程向けに、CPUファンと冷却系の動作を検査する Windows 10/11（64bit）専用デスクトップアプリです。インストール不要で、ブラウザー・Python・PowerShell・CMDを介さず起動できます。

ネコシステム社ブランドの公式配布用パッケージです。内部の実行ファイル名と設定保存先は、旧版からの自動起動・設定互換性を守るため `mknkLaptopFanChecker` のまま維持しています。

## 起動

1. ZIPを展開します（ZIP内から直接起動しないでください）。
2. 最上位にある **`mknkLaptopFanChecker.exe`** をダブルクリックし、Windowsの管理者確認で「はい」を選びます。
3. 初回または更新時に、公式PawnIO 2.2.0センサードライバーの導入確認が表示されます。CPU温度・RPMを読むには「はい」を選びます。

通常起動時は、デスクトップへ余白を残す1450×1100のウィンドウとして画面中央へ表示します。

画面だけ試す場合は、コマンドプロンプトから `mknkLaptopFanChecker.exe --demo` と指定できます。通常利用ではコマンド操作は不要です。

## バージョンの確認・更新

タイトルバーと画面右上に **v1.3.1** を表示します。常駐中は、タスクトレイのアイコンにマウスを重ねても確認できます。HTML検査レポートの末尾にもバージョンを記録します。

更新するときは、旧版のトレイアイコンを右クリックして「終了」を選んでからZIPを展開してください。新しいフォルダーの最上位にある `mknkLaptopFanChecker.exe` を起動し、v1.3.1の表示を確認します。

## 主な機能

- CPU温度・CPU負荷・CPU実働速度（GHz）・ファンRPMのリアルタイム表示とグラフ
- CPU温度が未検出のときの原因表示と［温度取得を再検出・修復］
- Windowsが報告するCPU基本速度の表示
- ソケット数・コア数・論理プロセッサ数の表示とHTMLレポートへの記録。タスクマネージャーのCPU構成表示に合わせ、Windows全体で有効なCPU構成をWindows APIから取得します（複数ソケット・複数プロセッサグループに対応）。取得不可時は推定値を表示しません。
- CPU実働速度はLibreHardwareMonitorが検出した各コアの動作クロック（MHz）の平均をGHzに換算し、約1秒ごとに更新します。基本速度とは別の値で、タスクマネージャーの速度や休止時間を含めた実効クロックとは測定方式が異なります。取得できない機種では「取得不可」と表示します。
- 待機 → CPU負荷 → 冷却の3工程による自動ファンテスト
- 設定温度（初期値92℃）で負荷を即時停止する保護機能
- CPUファンのRPMを特定できないPCでは、温度勾配と冷却量から間接判定
- 排気の増加・異音という人の確認も判定へ反映
- HTML検査レポートとCSV生ログの保存（CPU実働速度を含む。CSV末尾の `cpu_clock_ghz` 列はGHz、取得不可時は空欄）
- Windowsログイン時の自動起動とタスクトレイ常駐
- ［×］または［最小化］で画面を閉じても、タスクトレイで監視を継続
- 絶対高温、高温持続、低負荷時高温、急激な温度上昇の自動検知・通知・記録
- メモリ使用率の表示と、自動実行専用スマートブースト（初期OFF）

## スマートブースト（メモリ）

右側の「スマートブースト（メモリ）」で **「メモリ整理を自動実行」** をONに切り替えると、メモリ使用率や前回の実行時刻に関係なく1回すぐに整理します。ファンテスト・開始確認中は終了後、別の整理が実行中ならその完了後に実行します。待機中にOFFに戻すと取り消します。

その後は物理メモリ使用率を通常5秒ごとに確認し、85%以上が30秒続いた場合にバックグラウンドアプリのワーキングセットを整理します。自動再実行は直近の試行から30分以上空けます。設定と前回の時刻は保存され、再起動後も引き継ぎます。保存済みのON設定でアプリを起動しただけでは即時整理しません。

操作はON/OFFのみです。ファンテスト中・デモ中は実行せず、OFFまたは終了時には処理を中止します。通常のトレイ常駐中も監視を続けます。直近の実行時刻、整理したプロセス数、実行前後のメモリ使用率を表示します。

対象は同じユーザー・セッションのバックグラウンドプロセスです。ウィンドウを持つアプリ、操作中のアプリと同じ実行ファイル、Windowsフォルダー内のプロセス、重要なシステムプロセス、本アプリは除外し、確認できない対象はスキップします。プロセスの終了やファイル削除は行いません。メモリ使用率の低下や高速化を保証するものではなく、再読み込みで一時的に遅くなる場合があります。

Microsoft PC Managerのスマートブーストを参考にした、本アプリ独自のメモリ整理機能です。Microsoft PC Managerのインストールや連携は不要です。

## Windowsネイティブ起動

最上位の `mknkLaptopFanChecker.exe` は、C++で作成した64bit Win32 GUIランチャーです。Windows GUIサブシステムで動作するため、黒いコンソール画面は出ません。C++ランタイムは静的リンク済みで、`libc++.dll` や `libunwind.dll` は必要ありません。ランチャーは `runtime` 内の検査GUIへ引数と作業フォルダーを正しく引き継ぎます。

検査GUIとセンサーエンジンは、LibreHardwareMonitorとの互換性を保つためWindows Forms／.NET Framework 4.7.2を使用しています。これはWebアプリ、Electron、Pythonアプリではありません。通常のWindows 10/11には必要な.NET Frameworkが含まれます。詳しくは `NATIVE_COMPONENTS.md` を参照してください。

## 自動起動と異常発熱監視

画面右側の「Windowsログイン時に自動起動」を有効にすると、現在のWindowsユーザー用に、最高権限のログオンタスクとユーザー別 `Run` 監視起動を登録します。タスクが管理者専用のPawnIOセンサーへ接続し、`Run` 側がタスクの起動を再確認するため、次回ログオン時はUACを表示せずタスクトレイへ常駐します。

通常起動でも、ウィンドウの［×］または［最小化］を押すとタスクトレイへ収納され、監視を継続します。画面を戻すにはトレイアイコンをダブルクリックします。完全に終了する場合だけ、トレイアイコンを右クリックして「終了」を選びます。

自動起動時はCPU負荷テストを実行しません。温度・メモリ使用率を監視し、スマートブーストをONにしている場合は条件成立時にメモリを整理します。温度監視の初期設定では次を検知します。

| 検知 | 初期条件 |
|---|---|
| 設定上限温度 | 92℃以上 |
| 高温持続 | 85℃以上が約30秒継続 |
| 低負荷時高温 | 平均CPU負荷25%以下で80℃以上が約60秒継続 |
| 急上昇 | 60秒以内に15℃以上上昇し75℃以上 |

同種の通知は初期設定で10分間抑制します。検知記録は `%LOCALAPPDATA%\mknkLaptopFanChecker\HeatAlerts` にCSVで保存します。

アプリを更新・移動した後に通常起動すると、タスクと `Run` の両方を現在の保存場所へ自動修復します。フォルダーを移動した直後は、新しい場所の `mknkLaptopFanChecker.exe` を一度手動で起動してください。

ログオン時にはセンサードライバーの導入確認を表示しません。温度が未検出と表示される場合は、通常起動後に［温度取得を再検出・修復］を実行し、案内された場合はPCを再起動してください。

## 安全な検査手順

1. 安定した電源へ接続します。バッテリー搭載機はAC電源を使用します。
2. 機種に合った向きで安定した場所へ設置し、吸排気口を塞がないようにします。
3. HWiNFO、FanControl、Open Hardware Monitorなど、他のセンサー監視ソフトを終了します。
4. 異臭、煙、液体侵入跡、膨張バッテリーがあるPCでは負荷テストを実行しません。
5. 「自動テスト開始」を押し、排気と異音も確認します。
6. 高温保護停止した場合は冷えるまで待ち、ファン接続、埃、ヒートシンク密着、グリスを点検します。

本アプリはファン制御値、BIOS、Windows電源設定を書き換えません。

## 判定の読み方

- **正常傾向：回転数を直接確認** — RPMと温度応答の両方に正常方向の変化があります。
- **正常傾向（間接判定）** — CPUファンのRPMは特定できませんが、温度の安定または冷却工程の低下を確認しました。
- **再確認推奨／判定保留** — 測定時間、温度差、センサー情報が不足しています。
- **要点検／異常疑い** — 高温、冷却不足、回転未検出、または異音があります。

「正常傾向」は単回検査の結果であり、断続故障、軸受寿命、長時間負荷を保証しません。メーカー診断、目視、排気・異音確認と併用してください。

CPUファンと識別できた同一センサーを継続して使い、ケースファン・GPUファン・水冷ポンプ・名前だけでは用途が不明なFan #1などは直接判定から外します。低温での0 RPMや低回転は、それだけでは故障扱いにしません。ファンレス・水冷構成では、温度挙動とメーカー仕様を確認してください。

複数CPUでは最も高い有効なCPU温度を監視します。温度が取得できなくなった場合は負荷を止めて判定を保留し、負荷処理にも独立した時間上限を設けています。CPU数が負荷ワーカー数を超える環境（64論理プロセッサ超など）では、全CPUの負荷検査を保証できないため結果に「部分検査」と明記します。92℃はアプリの初期保護値で、すべてのCPUに共通する故障温度ではありません。

## 対応と技術情報

- 対応OS：64bit版 Windows 10 / 11
- 必要環境：.NET Framework 4.7.2以上（通常はWindows 10/11に含まれます）
- ネイティブ起動部：C++／Win32 x64
- センサー：LibreHardwareMonitor 0.9.6
- センサードライバー：PawnIO 2.2.0（同意した場合のみ導入・修復。実行前にSHA-256を照合）
- アイコン：提供写真を基にした「ゆりちゃん」とCPUファンの専用マルチサイズアイコン（EXE、ウィンドウ、タスクバー、通知領域で共通）
- アプリ本体：MIT License
- LibreHardwareMonitor：MPL-2.0。詳細は `licenses` フォルダーを参照してください。

EC・BIOS・マザーボードがCPUファンのRPMを公開しない場合、またはCPUファンを識別できない場合、RPMは「未特定」と表示されます。これはファン停止を意味しません。その場合は温度挙動による間接判定と、人による排気・異音確認を使います。

CPU基本速度は、Windowsの［パフォーマンス］→［CPU］に表示される「基本速度」に合わせ、公開Windows API `CallNtPowerInformation(ProcessorInformation)` の `PROCESSOR_POWER_INFORMATION.MaxMhz`（Windowsが報告する指定最大クロック値）から取得します。WMIの `Win32_Processor.MaxClockSpeed`、現在の瞬間的な動作クロック、ターボ速度は使用しません。Windows APIが値を返さない場合は「取得不可」と表示します。

PawnIOはWindowsへ導入されるセンサードライバーです。不要になった場合は、Windowsの「インストールされているアプリ」からPawnIOをアンインストールできます。アプリが同意なしに導入することはありません。
